# watchAny 2.0

A modern, fast, and feature-rich media streaming client built with Flutter, supporting Stremio/Cinemeta addons, torrent/debrid streaming, advanced metadata tracking, and a premium dark user interface.

## Key Features

- **Movies & TV Shows**: Browse and stream movies and series powered by Stremio addon catalogs and metadata.
- **Anime & Manga integration**: Direct AniList sync, tracking, and seamless detail cards.
- **Extensions / Addons Engine**: Dynamic repository syncing, live update checker, and extensible stream providers.
- **Responsive Layout**: Designed for phones, tablets, and desktop displays.
- **Built-in Diagnostics**: Logs and diagnostics viewer built-in.

## Installation

Download the latest version for your platform from the [Releases](https://github.com/Fluffy-The-Penguin/watchAny-2.0/releases) section:
- **Windows**: Download `watchany_setup.exe` (Windows Installer).
- **Android**: Download the split APK matching your device's architecture (e.g., `arm64-v8a`, `armeabi-v7a`, or `x86_64`).

## Development Setup

1. Install [Flutter SDK](https://flutter.dev/docs/get-started/install).
2. Clone the repository.
3. Run `flutter pub get` to install dependencies.
4. Run the app using `flutter run` or build via `flutter build <platform>`.
